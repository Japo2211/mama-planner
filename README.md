# Mamá Planner

## 👉 [Abrir la app: japo2211.github.io/mama-planner](https://japo2211.github.io/mama-planner/)

### Cómo instalarla en el iPhone
1. Abre el enlace de arriba en **Safari**.
2. Toca **Compartir** (cuadrado con flecha ⬆️).
3. Toca **"Agregar a pantalla de inicio"** y luego **Agregar**.
4. Abre la app desde el ícono de la luna con la hojita.

Tus datos quedan guardados solo en tu teléfono.
